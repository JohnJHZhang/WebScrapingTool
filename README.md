# 个人开发的程序
# 这是一款基于 Python + CustomTkinter 开发的可视化、轻量化、跨平台网页内容抓取工具，专为零基础用户打造，集文字提取、图片批量下载、多语言、双主题、自适应界面于一体，完美解决网页内容快速保存的需求。

一、核心功能
自动提取网页纯文本内容，支持实时预览，一键保存为 .txt 文本文件。
智能过滤无效图片、Base64 图片，支持图片预览；单张勾选 / 全选精准控制，仅下载选中的图片。
自由选择本地保存文件夹，文件自动命名，分类存储文字与图片。

二、界面与交互
支持拖动放大 / 缩小，自适应布局，缩放无错乱、无遮挡。
文字预览、图片预览双标签页布局完全对称，整洁无遮挡，极简美观。
双主题切换：支持浅色 / 深色模式，版权文字、所有控件自动适配配色，视觉体验统一。
语言支持：简体中文 / 繁体中文 / 英文 / 日文 / 韩文一键切换，全界面文本同步翻译。

三、稳定性与技术亮点
修复核心 BUG：彻底解决图片无法抓取、预览失败、相对路径 / HTTPS 图片加载异常问题；
高容错性：无效图片、网络失败自动跳过，程序不崩溃、无卡顿；
安全请求：自带浏览器 UA 伪装，兼容绝大多数主流网页；
纯 GUI 操作：无命令行，一键抓取、一键下载，新手零门槛使用。

四、适用场景
快速保存网页文章、教程、文案等文字内容；
批量下载网页图片，支持选择性保存，避免冗余；
多语言 / 双主题需求的用户，适配不同使用习惯；
办公、学习中需要快速提取网页资源的轻量化场景。
